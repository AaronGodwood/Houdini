# Return the Houdini Shiny application object

Called internally by
[`run_app`](https://aarongodwood.github.io/Houdini/reference/run_app.md).
You can also pass the result directly to
[`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html) if you
need more control.

## Usage

``` r
houdini_app()
```

## Value

A Shiny app object.
