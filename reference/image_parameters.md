# Parameter values carried by each page of a figure RTF

The figure equivalent of the parameters in
[`table_info_from_pages()`](https://aarongodwood.github.io/Houdini/reference/table_info_from_pages.md):
lets the UI offer the same parameter filter for figures as for tables.

## Usage

``` r
image_parameters(path)
```

## Arguments

- path:

  Path to the .rtf file

## Value

Character vector of unique parameter values, in document order
