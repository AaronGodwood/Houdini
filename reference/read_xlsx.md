# Read a houdini xlsx workbook

Same format as the app's Excel export: see
[`parse_xl()`](https://aarongodwood.github.io/Houdini/reference/parse_xl.md).

## Usage

``` r
read_xlsx(path)
```

## Arguments

- path:

  Path to the .xlsx file

## Value

list(config, selections); see
[`parse_xl()`](https://aarongodwood.github.io/Houdini/reference/parse_xl.md)
