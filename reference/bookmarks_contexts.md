# Contexts of extracted bookmarks

Contexts of extracted bookmarks

## Usage

``` r
bookmarks_contexts(bm)
```

## Arguments

- bm:

  The value returned by
  [`extract_bookmarks()`](https://aarongodwood.github.io/Houdini/reference/extract_bookmarks.md)

## Value

Named character vector (name -\> context), or an empty vector if `bm`
carries no context attribute
