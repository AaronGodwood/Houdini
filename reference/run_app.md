# Launch the Houdini shiny app

Opens the Houdini app in your default browser

## Usage

``` r
run_app(...)
```

## Arguments

- ...:

  arguments passes to
  [`runApp`](https://rdrr.io/pkg/shiny/man/runApp.html) e.g. `port`,
  `launch.browser`.

## Value

Called for its side effects of launching the app
