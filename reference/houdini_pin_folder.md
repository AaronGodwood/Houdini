# Pins a folder of RTF files to POSIT Connect

Pins a folder of RTF files to POSIT Connect

## Usage

``` r
houdini_pin_folder(path, figure_path = NULL, name)
```

## Arguments

- path:

  the file path to the folder of .RTF files to pin

- figure_path:

  a second optional folder path for when figures are stored separately
  from tables

- name:

  the name the pin will take on POSIT Connect

## Value

The fully qualified name of the new pin invisibly
